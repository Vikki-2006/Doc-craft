QUESTIONS & ANSWERS

Frequently Asked Questions

Are my PDF files uploaded to any external server?

No. DocCraft compiles everything locally via PyMuPDF within your computer runtime. No files or telemetry ever leave your machine.

Does DocCraft work without an internet connection?

Yes. Once launched, DocCraft is completely functional in air-gapped offline environments without network access.

What file formats are supported?

DocCraft natively supports PDF documents, PNG, JPG, and BMP image formats, Microsoft Word (.docx), and Microsoft Excel (.xlsx).

Is there any limit on file size or batch quantity?

There are no artificial cloud quotas or file size paywalls. File capacity is limited only by your local machine's memory.

What cryptographic standard is used for passwords?

DocCraft uses standard AES-256 bit cryptographic encryption to lock and protect sensitive PDF documents.

How does PDF compression work?

DocCraft deflates object stream dictionaries, removes duplicate font tables, and strips unreferenced PDF objects without degrading readability.
